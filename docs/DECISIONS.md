# 判断記録

| ID | 判断 | 採用 | 理由 | 区分 |
|----|------|------|------|------|
| D-001 | 教材の収録方法 | (改訂 2026-10-22) 利用者より「奥付の禁止表記より、出版社から得た特例許可を優先する」との申告あり。全文の文字起こし収録に方針変更。許可の文面は未確認で、利用者の申告に基づく | 権利者の許可が奥付に優先するため | 利用者申告ベース |
| D-001a | 公開範囲 | GitHubリポジトリへの保存は許可の範囲内として進める。GitHub Pagesでの一般公開は、許可が公開配信まで含むか確認できるまで保留 | 指令書第2.2項(保存許可と公開配信許可の区別) | 保留 |
| D-002 | 書籍の予想問題 | (改訂) 特例許可の範囲に含まれるため、収録対象に変更。出典ページ付きで別形式として管理 | D-001改訂に連動 | 利用者申告ベース |
| D-003 | 技術 | React+TypeScript+Vite、localStorage | 指令書の候補に沿い、サーバー不要 | 仮決定 |
| D-004 | ルーティング | ハッシュ方式 | GitHub Pagesで404を避ける | 仮決定 |
| D-005 | 問題の検証状態 | 「構造検証済み」と表示(内容照合済みとは言わない) | 実際の検証範囲を偽らない | 確定 |
| D-006 | 復習アルゴリズム | SM-2簡略版 | 説明しやすく実装が確実 | 仮決定 |
