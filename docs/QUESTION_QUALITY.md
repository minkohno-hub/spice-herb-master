# QUESTION_QUALITY — 問題・採点品質

- 現状: 正式問題0問。エンジン検証用サンプル17問（全17形式を1問ずつ）は題材が「アプリの利用ルール」であり教科書知識ではない。すべて `status: sample` と明示され、`selectForPractice` の既定では通常出題から除外されることをテストで保証。
- 正式問題の登録条件（validate.ts で機械検証）: 出典（SourceRef）必須、知識単位との対応必須、解説必須、四択の正解は1つ、正解インデックス範囲内。未検証問題を検証済みとして表示しない。
- 重複管理: 問題文＋形式の完全一致を重複候補として検出（品質管理画面に集計）。意味的な重複は今後、知識単位と出題観点で監査する。
- 記述式採点: 要点（RubricPoint）ごとのキーワード一致（NFKC・空白/句読点除去・長音吸収の正規化）で部分点を算出。必須要点の不足を明示。自動判定は「判定」として自己採点と分離保存し、ルールベースで確定できない回答は correct=null（要自己確認）として扱う。
- 採点テスト: 完全正答/誤答/空回答/表記揺れ/複数要点/一部要点/特殊文字/基準なし、を tests/grading.test.ts で検証済み。
