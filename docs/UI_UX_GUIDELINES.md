# UI_UX_GUIDELINES

- コンセプト: 知的・上質・自然・清潔・洗練・直感的。植物系の落ち着いた緑（--accent #3f6212）を基調、背景 #faf9f4、カード型レイアウト、角丸14px。装飾は控えめ。
- スマホ優先: タップ領域44px以上、入力フォント16px（iOSの自動ズーム回避）、セーフエリア配慮、縦積みレイアウト。PCではリーダーが目次/本文の分割表示。
- 情報設計: ホームに最優先操作（続き/今日の復習/ランダム/苦手/模試/単語帳/書籍/進捗/目標）を集約。品質管理は通常学習導線から分離した専用画面。
- アクセシビリティ（WCAG 2.2 AA目標）: フォーカス表示、aria-label/aria-live、色以外（✓/−・文言）による状態表示、フォームラベル、ダークモード。実機・スクリーンリーダーでの検証は未実施（QUALITY_REPORTに明記）。
- 状態表示: 読み込み・空結果（「検証済み問題がまだありません」と理由を明示）・正誤フィードバック・保存先の注意書き（フッター常時表示）。
