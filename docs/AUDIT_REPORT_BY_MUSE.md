## CI e2e 失敗（F-01）

- main の直近コミット（748270a3、e4dc2b55、6b976d7c）はいずれも check 成功・e2e のみ失敗。
- GitHub コネクタのツール一覧を列挙し、Actions ログ取得手段が存在しないことを確認した。未認証 API からも job ログは取得できなかった。
- ci.yml と playwright.config.ts の精査では明白な設定欠陥は見つからなかった（webServer タイムアウト 180 秒、テスト 60 秒、expect 15 秒はいずれも妥当な余裕）。
- ローカルで「高負荷時に同種のタイムアウト失敗が発生し、負荷が下がれば合格する」ことを再現・確認した。CI でも同様の環境要因が考えられるが、ログがないため断定はしない。
- 対応: 次回失敗時に証拠（test-results の trace・スクリーンショット）を Artifacts へ保存するワークフロー改訂案を docs/CI_E2E_PROPOSAL.md に用意した。判定は BLOCKED（適用はユーザーの Web UI 操作待ち）。

## 写真識別問題（F-02）

- 現行の figure 形式 17 問は表データに基づく出題であり、写真識別は未実装。
- 収録画像はページ全体（幅 1000px の WebP）で、品目写真と同じページに品目名の見出し・プロフィール表・本文が含まれる。そのまま出題すると答えが画像内の文字で判明し、識別問題として成立しない。
